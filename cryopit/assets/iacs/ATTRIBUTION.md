# IACS snow grain symbols

These PNG renderings of the official IACS/ICSSG snow grain classification
symbols (Fierz, C. et al., 2009: The International Classification for Seasonal
Snow on the Ground, UNESCO-IHP) are bundled from the MIT-licensed
[snowpyt](https://github.com/ArcticSnow/snowpyt) package by Simon Filhol.
Used in CryoPit's rendered snow-profile figure. See snowpyt's LICENSE (MIT).
